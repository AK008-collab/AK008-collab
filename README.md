## 🧩 Featured Engineering Work

### 🚆 [Train-to-Train Communication & Collision Prevention](projects/train-to-train-communication/)

ESP32-based railway safety prototype using wireless communication and RSSI-based relative proximity estimation. The system combines communication, motor control, warning indicators and safety-state logic.

**ESP32 · ESP-NOW · RSSI · L298N · Embedded C · IoT**

### 🪖 [IoT-Based Smart Helmet for Rider Safety](projects/smart-helmet/)

An emergency-response-focused smart helmet concept designed to help communicate a rider’s location and send alerts after a possible accident. GPS/GSM emergency communication is the primary value proposition; alcohol detection is an additional preventive safety feature.

**ESP8266/ESP32 · MPU6050 · GPS · GSM · Embedded C · IoT**

### ⚡ [Thermoelectric Energy Recovery](projects/thermoelectric-energy-recovery/)

Engineering project exploring recovery of automobile exhaust heat using thermoelectric generation and the Seebeck effect.

**TEG · Seebeck Effect · Waste Heat Recovery · Automotive Engineering**

### 🤖 [CampusCourier — Autonomous Indoor Delivery Robot](projects/campus-courier/)

Simulation-first ROS 2 project. Milestone 1 implements a testable delivery mission state machine and ROS topic interface. Mapping, simulation, Nav2 navigation, and obstacle avoidance are planned milestones and are not claimed as complete.

**ROS 2 Humble · Python · rclpy · Mission State Machine**

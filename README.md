## 🧩 Featured Engineering Projects

### 🚆 Train-to-Train Communication & Collision Prevention
An ESP32-based prototype for detecting the relative proximity of two trains using wireless communication and RSSI-based distance estimation. The system is designed to trigger motor stopping and alerts when trains approach defined safety thresholds, with a web dashboard for monitoring.

**Technologies:** ESP32 · ESP-NOW · RSSI · L298N · Sensors · IoT · Web Dashboard

### 🪖 Smart Helmet Safety System
An IoT-based two-wheeler safety prototype combining helmet detection, alcohol detection, motion sensing, GPS/GSM alerts and ignition control. The system is designed to detect unsafe conditions and provide emergency notifications after a crash.

**Technologies:** ESP8266/ESP32 · Embedded C · MPU6050 · GPS · GSM · Sensors · IoT

### ⚡ Thermoelectric Energy Recovery
A project exploring the use of thermoelectric generators to recover useful electrical energy from automobile exhaust heat using the Seebeck effect.

**Focus:** Thermoelectric Generation · Energy Recovery · Automotive Applications

# Thermoelectric Energy Recovery — Testing Checklist

## Thermal Measurements

- [ ] Measure hot-side temperature
- [ ] Measure cold-side temperature
- [ ] Record temperature difference over time
- [ ] Verify thermal interface quality

## Electrical Measurements

- [ ] Open-circuit voltage measured
- [ ] Loaded voltage measured
- [ ] Load current measured
- [ ] Electrical power calculated from measured voltage and current
- [ ] DC-DC conditioning stage tested

## Performance

- [ ] Compare output at different temperature differences
- [ ] Characterize stability over time
- [ ] Estimate conversion efficiency using measured input/output quantities
- [ ] Check thermal limits of the TEG and surrounding components

## Evidence to Add

- Temperature logs
- Voltage/current measurements
- Experimental graphs
- Hardware photographs
- Circuit diagram
- Final analysis

Do not report theoretical values as experimental results.

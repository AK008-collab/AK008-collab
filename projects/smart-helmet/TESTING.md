# Smart Helmet — Testing Checklist

## Safety Inputs

- [ ] Helmet-wearing detection tested
- [ ] Alcohol-sensor threshold calibrated
- [ ] Accelerometer readings verified
- [ ] False-trigger conditions tested

## Vehicle Control

- [ ] Ignition remains disabled when safety conditions are not met
- [ ] Relay operation verified
- [ ] Controller reset behaviour tested
- [ ] Power isolation between controller and actuator stage verified

## Emergency Response

- [ ] GPS acquisition verified outdoors
- [ ] GSM communication verified
- [ ] Emergency message format verified
- [ ] Crash-event sequence tested under controlled conditions

## Evidence to Add

- Circuit/wiring diagram
- Hardware photographs
- Firmware source
- Sensor calibration values
- Serial logs
- Test results

Only measured results from the actual prototype should be added to the final report.
